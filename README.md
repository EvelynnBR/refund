# Projeto de Solicitação de Reembolso (Refund)

Este é um projeto front-end simples que simula uma aplicação para solicitar e gerenciar reembolsos de despesas. Ele permite que o usuário adicione despesas, categorize-as, e veja um resumo do total a ser reembolsado, tudo com manipulação dinâmica do DOM utilizando JavaScript puro.

## ✨ Funcionalidades

- **Adicionar Despesas:** Formulário para inserir o nome, categoria e valor de uma nova despesa.
- **Listagem Dinâmica:** As despesas adicionadas são exibidas em uma lista em tempo real, sem a necessidade de recarregar a página.
- **Cálculo Automático:** O valor total e a quantidade de despesas são atualizados automaticamente a cada adição ou remoção.
- **Remoção de Despesas:** É possível remover uma despesa da lista clicando no ícone de lixeira.
- **Formatação de Moeda:** O campo de valor formata automaticamente o número digitado para o padrão monetário brasileiro (BRL).
- **Interface Limpa:** Design simples e intuitivo para uma fácil experiência do usuário.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Para a estrutura semântica da página.
- **CSS3:** Para a estilização e layout (através do arquivo `styles.css`).
- **JavaScript (Vanilla):** Para toda a lógica da aplicação, incluindo manipulação de eventos, criação de elementos no DOM e cálculos.

## 🚀 Como Executar

Como este é um projeto puramente front-end, você não precisa de um servidor ou dependências complexas para executá-lo.

1.  Clone este repositório ou faça o download dos arquivos.
2.  Navegue até a pasta do projeto.
3.  Abra o arquivo `index.html` em seu navegador de preferência (Google Chrome, Firefox, etc.).

Pronto! A aplicação estará funcionando.
